============================================================
  S-Patch AccurKardia 자동화 — Windows 사용 가이드
============================================================

[사전 준비]
  1. AccurKardia 앱이 검사 진행 중 상태여야 합니다.
     ("My Study Progress" 화면이 표시되어야 함)
  2. Android 기기를 USB로 PC에 연결하고
     USB 디버깅을 활성화하세요.
     (설정 → 개발자 옵션 → USB 디버깅)
  3. 기기에 "USB 디버깅 허용" 팝업이 뜨면 "허용"을 누르세요.

------------------------------------------------------------
[최초 1회 — 설치]

  install.bat 를 더블클릭하세요.
  (보안 경고가 뜨면 "추가 정보" → "실행" 클릭)

  자동으로 설치됩니다:
    - Python 3.12 (없는 경우 winget으로 자동 설치)
    - Node.js LTS (없는 경우 자동 설치)
    - ADB (android-platform-tools 자동 다운로드)
    - Appium
    - UiAutomator2 드라이버
    - Python 패키지 (requirements.txt)

  설치 완료 메시지가 나올 때까지 기다리세요.
  오류 발생 시 install.bat를 다시 실행하거나
  관리자 권한으로 실행해보세요.

------------------------------------------------------------
[실행]

  run.bat 를 더블클릭하세요.

  - Appium 서버가 별도 창에서 시작됩니다.
  - 브라우저가 자동으로 열립니다 (http://127.0.0.1:5002).
  - run.bat 창을 테스트 중에는 닫지 마세요.

  브라우저에서:
    1. 기기 선택
    2. S-Patch 시리얼 번호 입력
    3. 실행 시간 / 주입 간격 설정
    4. "Start Test" 클릭

------------------------------------------------------------
[종료]

  STOP.bat 를 더블클릭하거나
  run.bat 창을 닫으세요.

------------------------------------------------------------
[문제 발생 시]

  1. install.bat를 관리자 권한으로 재실행해보세요.
  2. %TEMP%\ak_install.log 파일을 확인하세요.
  3. USB 케이블을 다시 연결하고 재시도하세요.
  4. Windows Defender 또는 백신이 차단하는 경우
     해당 폴더를 예외로 추가하세요.
