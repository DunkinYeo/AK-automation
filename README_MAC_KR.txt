============================================================
  S-Patch AccurKardia 자동화 — macOS 사용 가이드
============================================================

[사전 준비]
  1. AccurKardia 앱이 검사 진행 중 상태여야 합니다.
     ("My Study Progress" 화면이 표시되어야 함)
  2. Android 기기를 USB로 Mac에 연결하고
     USB 디버깅을 활성화하세요.
     (설정 → 개발자 옵션 → USB 디버깅)
  3. 기기에 "USB 디버깅 허용" 팝업이 뜨면 "허용"을 누르세요.

------------------------------------------------------------
[최초 1회 — 설치]

  install.command 를 더블클릭하세요.

  자동으로 설치됩니다:
    - Homebrew
    - Python 3.10+
    - Node.js / npm
    - ADB (android-platform-tools)
    - Appium
    - UiAutomator2 드라이버
    - Python 패키지 (requirements.txt)

  Mac 비밀번호를 요청하면 입력 후 Enter를 누르세요.
  설치 완료 메시지가 나올 때까지 기다리세요.

------------------------------------------------------------
[실행]

  run.command 를 더블클릭하세요.

  - Appium 서버가 자동으로 시작됩니다.
  - 브라우저가 자동으로 열립니다 (http://127.0.0.1:5002).
  - 이 터미널 창을 테스트 중에는 닫지 마세요.

  브라우저에서:
    1. 기기 선택
    2. S-Patch 시리얼 번호 입력
    3. 실행 시간 / 주입 간격 설정
    4. "Start Test" 클릭

------------------------------------------------------------
[종료]

  STOP.command 를 더블클릭하거나
  run.command 창에서 Ctrl+C 를 누르세요.

------------------------------------------------------------
[문제 발생 시]

  1. install.command 를 다시 실행해보세요.
  2. /tmp/ak_install_*.log 파일을 확인하세요.
  3. USB 케이블을 다시 연결하고 재시도하세요.
